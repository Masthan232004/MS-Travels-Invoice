# M S Travels Bill Creator

A small static bill creator built with plain HTML, CSS, and JavaScript. It runs in the browser and does not need a server or build step.

## Files

- `index.html` — the bill form, live preview, calculations, and print layout.
- `Signature.png` — the contractor signature used on the bill. Keep this filename and capitalization unchanged.

## Run locally

Open `index.html` in a current browser. Enter the bill details, choose Petrol or Diesel, then click **Save as PDF** and select **Save as PDF** in the print dialog.

## Privacy

The bill is a static, browser-only app: entered bill details are not sent to a server or saved by the app. The signature image is included in the deployed site and can be downloaded by visitors. GitHub Pages sites are publicly accessible, including sites published from private repositories, so do not publish this version if the signature must remain private. See [GitHub's Pages publishing documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
