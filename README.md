# M S Travels Bill Creator

A small static bill creator built with plain HTML, CSS, and JavaScript. It runs in the browser and does not need a server or build step.

## Files

- `index.html` — the bill form, live preview, calculations, and print layout.

## Run locally

Open `index.html` in a current browser. Choose **Rent per day** to enter hire and fuel charges, or **Rent per KM** to calculate the rent from the meter readings and per-kilometer rate. Then click **Save as PDF** and select **Save as PDF** in the print dialog.

## Privacy

The bill is a static, browser-only app: entered bill details are not sent to a server or saved by the app. GitHub Pages sites are publicly accessible, including sites published from private repositories. See [GitHub's Pages publishing documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
